# Extra demo videos

Drop **2–4 MP4 files** directly into this folder before starting the Backend.

When the real Creator Submission reaches `AI_PASSED` and the app starts human review, Clapback automatically adds up to four MP4s from this folder to that same Bounty's Review Round. Files are selected alphabetically, so prefixes such as `01-`, `02-`, and `03-` control their order.

These folder videos are intentionally treated as pre-approved demo fixtures. Only the video uploaded through the Creator app runs through ElevenLabs and the Deliverable verifier.

Local `*.mp4` files in this folder are ignored by Git.
