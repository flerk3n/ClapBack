# Uniqlo demo videos

Drop **2–4 MP4 files** for the Uniqlo **Men's Outfit Haul** Bounty directly into this folder before starting the Backend.

When the real Uniqlo Creator Submission reaches `AI_PASSED` and the app starts human review, Clapback automatically adds up to four MP4s from this folder to that Bounty's Review Round. Files are selected alphabetically, so prefixes such as `01-`, `02-`, and `03-` control their order. Other Bounties never load videos from this folder.

These folder videos are intentionally treated as manually curated, pre-approved demo fixtures. Only the video uploaded through the Creator app runs through ElevenLabs and the Deliverable verifier. Ensure every folder MP4 shows a men's outfit and is itself **under 1 minute**; the Backend does not inspect or derive metadata from these fixtures.

Local `*.mp4` files in this folder are ignored by Git.
